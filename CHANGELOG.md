# 2.5.0

- Adds private hunger text reminders: Off, Chat, On-screen, or Both.
- Configurable repeat interval from 0 to 120 minutes, including fractions. Zero means once per hunger episode; default is three minutes.
- Test reminder button; reminders pause during combat and feeding.
- Explains when no suitable allowed food is available.
- Whole feeding icon turns red when no suitable food is available.
- Current pet diet appears in the button tooltip.
- Prominent CHECK TO BLOCK instruction above food rows.

Original engine: Gideon (FeedPetForever, MIT). Adaptation and enhancements: OpenAI Codex.
User tested reminders in-game; Lua and behavior checks pass. Intended for Forever 1.60.1 only.
