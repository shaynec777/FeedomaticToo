# Ammo upgrade recommendations - local preview

Restart WoW after installation to load the new modules. Open `/ht ammo` (or Ammo > Settings), click **Upgrades**, and check **Enable upgrade recommendations**. Ammo Reminder itself must also be enabled. Include engineered ammo defaults off. Both choices are saved per character.

- Bow/crossbow users get arrows; gun users get bullets. Thrown weapons and wands receive no ammo recommendation.
- Compare ammo you actually have left against the strongest usable option in the curated catalog. An empty ammo-slot selection shows a red depleted warning; the strongest usable compatible ammo remaining in your bags becomes the comparison baseline and gets an equip reminder. Better carried ammo is called out with an equip reminder. This is advice only; the addon does not buy, craft or equip ammo.
- Sources name a faction-accessible vendor and zone, or Engineering skill and acquisition instructions. Tradeable crafted ammo can be bought from an engineer/Auction House without learning Engineering. Level-60 bind-on-pickup crafted ammo requires a readable Engineering skill of 300 for a crafting recommendation; schematic availability is still your responsibility. Already-carried ammo does not require crafting it again.
- If no current upgrade is available, show the next higher-damage option at a future level, when one exists in the curated catalog. All ranks above the beta cap are reference options, not a guarantee of current beta availability.
- The existing ammo list adds a red **[Obsolete]** beside lower-damage, level-eligible ammo of your current weapon's type only when a stronger option passes the same filters. Disabling engineered ammo removes it from that comparison, even when carried. Disabling upgrades or Ammo Reminder removes the labels. Deprecated/test ammo is never recommended; unverified ammo stats are not guessed.
- Quest/drop/reputation/exchange ammo is considered only when carried, so unverified acquisition requirements cannot trigger obsolete labels. These source restrictions may omit an upgrade you could personally obtain; this is a conservative catalog, not a complete universal best-in-slot list.
- Inventory changes, equipment changes and levels refresh the open panels. Combat pauses detail reads; zoning waits for inventory readiness. Totals include bags/quivers/pouches and native carried-item totals, excluding banks.
- Upgrade notifications have their own enable checkbox, repeat interval (0.1-120 minutes; default 5), and destination (on-screen banner, chat, or both). They default off. Alerts require Ammo Reminder and upgrade recommendations to be enabled. They fire for depleted equipped ammo or a currently usable stronger option, including an equip reminder for available carried ammo. Depletion alerts use the same notification checkbox, interval and destination. Combat, death and inventory loading defer notices; two consistent checks confirm the recommendation before the first alert. Future-only upgrades stay in the panel. Low-stock reminder preferences and cadence are unchanged.

Reference data: 26 curated Wowhead Forever projectile records, read October 16, 2026. Standard vendor rows verified at each item page: Thurman Mullby (Stormwind City, Alliance) and Trak'gen (Orgrimmar, Horde) sell Rough/Sharp/Razor/Jagged Arrows and Light/Heavy/Solid/Accurate Slugs. Stat values and required levels come from the Forever projectile list. Engineering skill values come from Created by tables. No skill-to-use requirement is shown on the tradeable crafted ammo tooltips.

Ice Threaded ammo's Forever purchase reputation requirement was not confirmed by structured data (older comments conflict across eras), so it remains carried-only with faction source text marked unverified. Thorium Headed Arrow exchange/currency access and legacy/test entries also remain conservative.

Inputs: reference-data/ammo-upgrades.json. Regenerate: `python build-ammo-upgrade-data.py`. Regression checks: release-source/test-ammo-upgrades.lua plus existing ammo/UI and config suites, run with the local Lua 5.1 runtime. In-game visual and beta-specific requirement checks remain necessary.

Test first with level-appropriate weak ammo: open Upgrades, enable it, verify a source for your faction, then check red labels in the ammo list. On a gun character at level 15, toggling engineered ammo should change the best option between Heavy Shot (3.5 ammo DPS) and Crafted Heavy Shot (4.5 ammo DPS). Carry a stronger eligible ammo stack and check the equip message.

## Upgrade notification testing

Open `/ht ammo` > Upgrades. Enable recommendations and upgrade notifications, choose an interval and destination, then press Enter to save the interval. The first notice follows two consistent checks about five seconds apart; repeats follow the configured minutes while a usable upgrade remains. Check banner, chat and both. Use 0.1 minutes for a quick repeat test (checks run at five-second granularity). Equip the recommended ammo with stock remaining to stop upgrade notices. To test depletion, leave an exhausted ammo type selected while carrying weaker compatible ammo: expect a depleted warning, an equip reminder for the remaining stock, and recommendations compared against that stock. Replenishing the selected ammo clears the depletion warning. Combat, death, disabled parent settings and zoning must suppress them. The interval and destination are saved independently of low-stock reminders. Invalid intervals restore the previous value.
